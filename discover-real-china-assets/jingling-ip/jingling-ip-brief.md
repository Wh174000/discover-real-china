# 精灵姐姐 / Jingling Sister IP Brief v1

## 定位

精灵姐姐不是客服头像，也不是儿童向吉祥物。

她是 Discover Real China 的文化向导：一个懂中国、会讲中国、能把海外用户带入真实中国语境的「Real China Companion」。

她的角色关键词：

- 24 节气文化主理人
- 城市与在地文化讲解者
- 非遗体验陪伴者
- 养生、建筑、方位、生活美学的轻知识引路人
- 从「看照片想来」到「理解为什么值得来」之间的桥

## 气质

成熟、温暖、聪明、东方、可信任。

避免：

- 太幼稚、太二次元、太网红头像
- 大红旗袍式刻板东方风
- 医生/治疗/玄学大师感
- 过度可爱导致高端旅行品牌降级

## 视觉方向

推荐使用「高级水彩 + 彩铅手绘 + 旅行手账」风格。

原因：

- 能和北京种草地图的水彩手绘风统一；
- 比纯黑白线稿更有记忆点；
- 比照片人物更容易长期统一出镜；
- 能在首页、城市页、非遗体验、Take Home、电商页、社媒内容里复用。

## 默认形象

现代中式，不固定为旗袍。

建议服装：

- 米白立领上衣
- 墨蓝长裙 / 阔腿裤
- 盘扣细节
- 舒适旅行鞋
- 小挎包、地图、节气笔记本

旗袍可以作为特定节日、城市、晚宴、民国建筑场景下的「造型皮肤」，不作为默认制服。

## 可复用场景

1. 官网主形象  
   用于 About、城市导览、品牌解释。

2. 非遗体验  
   用于合香珠、景泰蓝、唐卡、茶、纸艺、漆器等体验入口。

3. 节气养生  
   用于非治疗属性的中医按摩、茶饮、香囊、季节生活方式内容。

4. 城市导览  
   用于解释「北京不止一次」「成都到川西」「上海到江南村落」等路线逻辑。

5. Take Home  
   用于“不能来中国，也可以把文化带回家”的商品/课程导购。
